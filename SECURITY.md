# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.
Email **contact@yunmail.cc.cd** with:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- the SDK version and Python version involved.

We aim to acknowledge reports within 3 business days and to ship a fix
or mitigation for confirmed issues as quickly as possible.
